# myFamily

A family management web application designed to help families organize and manage their daily activities in one place.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT

## Project Structure

```text
myFamily/
├── apps/
│   ├── web/       # Frontend application
│   └── api/       # Backend API
├── README.md
└── package.json
```

## Getting Started

### Prerequisites

- Node.js
- MongoDB
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/abdulkarimaklouk/myFamily.git
```

2. Navigate to the project directory:

```bash
cd myFamily
```

3. Install dependencies:

```bash
npm install
```

4. Configure your environment variables.

5. Start the application using the available development scripts.
